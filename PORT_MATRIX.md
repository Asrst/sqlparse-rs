## How the scanner works

Before the rule table runs, `spans::find()` does a prepass over the full input to
locate dollar-quoted strings (`$$...$$`) and block comments (`/*...*/`). At any
position where one of those spans starts, the scanner yields the whole span as a
single token and skips the contained characters entirely. Only if the span is
unclosed does the prepass position fall through to the rule table.

For every remaining position the rule table below runs top-to-bottom. The first
rule that matches yields its token. If nothing matches, a single-character
`Token.Error` is emitted (the Python `for...else` fallback).

## Notes on non-obvious rules

**Rule 3 — lazy whitespace**
The Python pattern `\s+?` is lazy, which means it matches exactly one whitespace
character per token. The Rust port replicates this by consuming a single character
when `is_py_ws()` returns true. Sequences of spaces produce one `Whitespace` token
each.

**Rule 10 — `%s` placeholder and the case-insensitive `s`**
The Python regex compiles with `IGNORECASE`, so `%S` and `%s` are both valid.
The Rust port must replicate this for the trailing `s` in `pct_placeholder()`.
A fuzz run caught a regression here: `%SET` was incorrectly matching as a full
placeholder. The fix checks for `s` or `S` case-insensitively but only when the
character immediately follows either a bare `%` or a closing `)` of a named group.

**Rule 13 — reserved word fast-path**
`CASE`, `IN`, `VALUES`, `USING`, `FROM`, `AS` always produce `Token.Keyword`
regardless of context. They fire before rule 45 (the general word lookup), so
they can never be classified as `Token.Name` even when used as an alias or column
name in SQL that sqlparse cannot structurally parse.

**Rule 15 vs rule 16 — names around dots**
Rule 15 matches a word that is *followed by* a dot (possibly with whitespace):
`schema.table` gives `Name "schema"` from rule 15. Rule 16 matches a word that
is *preceded by* a dot: the `table` part of `schema.table` is matched by rule 16
as a `Name`. Together they ensure dotted identifiers are never reclassified as
keywords even when the word is in the keyword dictionary (e.g. `t.select`).

**Rule 24 — double-quote fallback**
Rule 23 handles the standard `"..."` string with doubling and escape. Rule 24 is
only reached when rule 23 fails (unclosed string at EOF). It matches the empty
string `""` or a lazily-quoted string that ends at the first unescaped `"`.

**Rule 45 — keyword dictionary lookup**
The general word rule feeds into `lookup_keyword()`, which searches 9 ordered
dictionaries. The first dictionary that contains the uppercased word wins (same
as Python's `is_keyword()` with its ordered `_KEYWORDS` list). Words not found
in any dictionary become `Token.Name`.

**Rule 47 — PostgreSQL operators**
Handles JSON path operators (`->`, `->>`, `#>`, `#>>`), containment operators
(`@>`, `<@`), and the `?`, `?|`, `?&` existence operators. These are checked
before the general operator rules 48 and 49 to avoid being absorbed into longer
greedy matches.

## Original Python loop (the loop this Rust code replaces)

```python
def get_tokens(self, text, encoding=None):
    if isinstance(text, TextIOBase):
        text = text.read()

    if isinstance(text, str):
        pass
    elif isinstance(text, bytes):
        if encoding:
            text = text.decode(encoding)
        else:
            try:
                text = text.decode('utf-8')
            except UnicodeDecodeError:
                text = text.decode('unicode-escape')
    else:
        raise TypeError(f"Expected text or file-like object, got {type(text)!r}")

    delimited_spans = keywords.find_delimited_spans(text)
    span_openers = delimited_spans.openers

    iterable = enumerate(text)
    for pos, char in iterable:
        if pos in span_openers:
            resolved = delimited_spans.resolve(pos)
            if resolved is not None:
                end, ttype = resolved
                yield ttype, text[pos:end]
                consume(iterable, end - pos - 1)
                continue

        for rexmatch, action in self._SQL_REGEX:
            m = rexmatch(text, pos)

            if not m:
                continue
            elif isinstance(action, tokens._TokenType):
                yield action, m.group()
            elif action is keywords.PROCESS_AS_KEYWORD:
                yield self.is_keyword(m.group())

            consume(iterable, m.end() - pos - 1)
            break
        else:
            yield tokens.Error, char
```
